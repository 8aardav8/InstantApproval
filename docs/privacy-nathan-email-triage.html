Privacy Policy — Nathan Email Triage

Last updated: September 4, 2026

"Nathan Email Triage" is a personal automation tool built and used by a single individual (Aaron David) to manage his own email accounts. It is not a public product, is not distributed to other users, and has no commercial purpose.

What it accesses

This application connects to the owner's own Gmail accounts via Google's OAuth API, using read, compose (draft-only), and label-management (star) permissions. It does not have permission to send email on the owner's behalf.

What it does with that access

The application reads new email content to classify it for personal triage purposes (e.g. flagging items that need attention), runs this classification using local software the owner controls, and applies a star to messages it judges relevant. It may create draft replies for the owner's own review, which are never sent automatically.

Data sharing

Email content and metadata are not shared with, sold to, or processed by any third party beyond the infrastructure the owner directly controls (a local machine and, for classification of uncertain cases, the Anthropic API, used solely to determine urgency/importance — not for any other purpose).

Contact

This tool has a single owner and user. Questions can be directed to the account holder directly.
